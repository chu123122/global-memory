## 一、心动技术栈概览

### 公开技术文档（极客文档 geekdaxue.co）

心动有一套**开放技术文档库**，涵盖：

| 分类 | 内容 |
|------|------|
| **代码规范** | Go/Golang、JavaScript/TypeScript、C++、PHP |
| **评审要点** | 游戏前端评审、游戏后端评审、安全评议 |
| **架构指南** | 游戏后端架构 Guide Line |
| **运维** | Docker 容器化、CoreOS 集群、Ansible 自动化部署 |
| **服务** | AnySDK、GMTool、安全SDK、CDN、HTTPDNS |
| **安全** | 内存修改器原理+数值加密、DDoS攻击 |

### 关键发现

1. **心动有 C++ 代码规范**——入职后第一件事应该读这个，对齐编码风格
2. **游戏前端评审要点**——了解他们的 Review 标准
3. **后端架构 Guide Line**——即使做客户端，了解后端架构有助于理解 C/S 交互
4. **安全相关**——内存修改器原理+数值加密，和你的防作弊设计直接相关

### 技术栈推测

基于招聘信息和公开资料：
- **主引擎**：UE（火炬之光系列）+ 自研引擎（TapTap 相关）
- **后端语言**：Go 为主（有 Go 代码规范和 Go 工程师招聘）
- **前端**：JavaScript/TypeScript（TapTap 平台）
- **容器化**：Docker + CoreOS + Ansible
- **CDN/网络**：自建 HTTPDNS + CDN 接入

- 评价 2 条（整体评分需登录查看）

### 2026 届游戏引擎/客户端暑期实习面经（知乎）

一位面试者的经历包括：
- 技术面问 Unity/UE 基础
- 渲染技术（体积云）
- 引擎底层代码修改能力
- 面试官提到"UE 要改很多底层代码"

### 关键面试方向

1. **C++ 基础**：虚函数/智能指针/移动语义（你已有准备）
2. **引擎底层**：UE GC/反射/TaskGraph（你的短板，重点补）
3. **项目深挖**：43 次出现频率最高（讲清楚做了什么、怎么做、遇到什么问题）
4. **多线程**：mutex/atomic/condition_variable（你的短板）
5. **网络同步**：帧同步 vs 状态同步（你的强项）
