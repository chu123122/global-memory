# 接入索引

> AI 接入本 harness 的主目录。CLAUDE.md（常驻铁律）一行指到这里。
> 人类向架构导览不在此——见根目录 README。
> 不是大目录：只承载「主目录」+「非 skill 入口」两类。

## 0. 两套「四层」消歧（接入第一眼）

本 harness 只有一套架构，但有两个**正交视角**，别当层级嵌套——你会在两处都看到「四层」，所指不同维度：

- **载体四层（结构 · "用什么机制承载"）**：`L1 Rules` / `L2 Skills` / `L3 Subagent` / `L4 Scripts`。静态组件清单，见根目录 README 架构图，是你点得开的文件/目录。
- **生命周期四层（功能 · "工作如何流转"）**：`执行层`→`沉淀层`→`反馈层`→`维护层`。一次任务的时间纵切，判断只住执行层，外三层纯契约。**本索引 §1 及 `rules/` 下四份层规格说的就是这套。**

两套交叉，非一一对应：一个载体常横跨多个生命周期层，一个生命周期层也由多种载体拼成。

| 载体组件 | 服务的生命周期层 | 怎么服务 |
|---------|----------------|---------|
| L1 Rules | 全程约束 | 19 条铁律辖全生命周期；`rules/` 四份层规格即四层契约正文 |
| L2 Skills | 驱动执行层 · 触发沉淀层 | `/work` 编排任务推进；产物落地触发入库 |
| L3 Subagent | 执行层（分派）· 维护层（巡检） | 按耦合度派 work-agent 等；guardian/log-triage 任维护 |
| L4 Scripts | 反馈层 · 维护层 · 执行层门禁 | retrieve 跑召回，health 跑巡检，gate hook 实时拦截 |

> 要找文件 → 载体四层（README）；要懂流程 → 生命周期四层（下方 §1）。
> 历史名「三层金字塔（Script→Skill→Agent）」= 工作粒度偏好（能用下层机制就不用上层），是载体四层中三个机制的取用次序，非独立架构；v1.0.0 起并入载体四层叙述。

## 1. 主目录：四层规格在哪、何时加载

判断只住执行层（AI+人），外三层纯契约。按需 just-in-time 加载，走显式相对路径（本文件在 `rules/`，层规格同目录）。

| 层 | 规格文件 | 何时加载 | 主拉手 |
|----|---------|---------|--------|
| 执行层 | `执行层.md` | 推进任务、code review、TDD、路由判断时 | work SKILL Step3 链入 |
| 沉淀层 | `沉淀层.md` | 要写记忆、拿不准写哪/什么格式时 | 沉淀触发（见下 §2.1） |
| 反馈层 | `反馈层.md` | 几乎不用 AI 读（hook 自动跑）；想懂召回契约时读 | — |
| 维护层 | `维护层.md` | 巡检/版本治理/改 hook 前 | maintain 入口 / 改机件前 |

## 2. 非 skill 入口：没被 slash/hook 自动接的需求

### 2.1 写记忆 → 去哪

触发信号（盲区 / bug / 风格纠正 / 跨项目规范 / 架构决策 / 面试 / "记住这个"）→ 对应分类。

**完整触发表 + 模板 + lint = `沉淀层.md`「接入流程（信号→入库）」（单一源）**，本索引不复述，只导航过去。

### 2.2 维护 → 跑哪个

| 想做 | 入口 |
|------|------|
| 只读总检查 | `maintain.py doctor` |
| 安全本地修复 | `maintain.py fix`（人确认） |
| 提交同步 | `maintain.py sync --source manual` |
| 人类主控台 | `../harness/control_panel.bat` |

全套工具手册（人类向）见 `../MAINTENANCE.md`。

### 2.3 想懂某层怎么运作 → 读哪份

→ 见上 §1 主目录，按层取 `<层>.md`。

### 2.4 系统拓扑导航

- task 文档 / 记忆库**位置** → `project_registry.json` 单一源（机制细节在操作细则，不在此）。
- 条文↔强制点映射（哪条铁律被哪 hook 以什么强度强制）→ `../RULE_ENFORCEMENT_MATRIX.md`。
- **有哪些工具 / 归哪层 / 新工具怎么接入** → `../docs/工具组件总览.md`（全量逐脚本表在 `../docs/scripts-registry.md`）。
- **主循环里有哪些 hook / 各日志在哪怎么读** → `../docs/主循环与日志地图.md`（接线顺序契约在 `../docs/hook-chain.md`）。

## 3. 已自动接入，不进本索引

- 开工/继续任务 → `/work`（skill 自动）
- 学习 → `/learn`（skill 自动）
- 每轮记忆召回 → `retrieve_inject.py`（UserPromptSubmit hook 自动）
