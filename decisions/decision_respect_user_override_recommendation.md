# 尊重用户「不动」拍板，不二次说服

## 决定

用户对 AI 推荐选项明确拒绝（「不动」/「保留」/「不开新任务」）时：

1. 记录用户选择 + 拒绝理由（如有）入决策队列「已决」
2. 复盘节不再列「应该改选 X」二次说服
3. 写明「待复审条件」（什么情况下重审）

## 备选方案

- A 反复推荐到用户改主意：损耗信任，AI 角色越位
- B 沉默接受不记录：丢失决策痕迹
- **C 记录 + 不复审**（选）：尊重 + 留痕

## 理由

- 决策权在用户，AI 推荐 ≤ 信息整合 + 选项呈现
- 反复说服 = 把决策权当协商权，越位
- 用户选「不动」常因有 AI 看不到的上下文（精力分配 / 时机 / 战略侧重）
- 留观察 ≠ 失败决策，是一种合法选项

## 适用范围

- 适用：用户拍板后归档复盘节、跨会话再提起时
- 不适用：用户决策违反硬约束（D10 不可逆操作 / 安全边界）→ 此时必须阻止

## 复审条件

- 用户主动重启该决策讨论
- 实测数据严重恶化（比如「不动」选项导致系统不可用）
- 跨任务出现新证据
