# 维护层规格

> 同构骨架：定位 → 职责边界 → 接入 → 接出 → 本层细则 → 引用铁律 → 强制点。
> R 编号权威 = `../docs/spec/RULE_ENFORCEMENT_MATRIX.md`。

## 定位

观测前三层（执行/沉淀/反馈）健康，提议修复/淘汰，护住 harness 机件。**纯契约层 + 只读优先**：默认只读不回写，写动作（fix/sync/改 hook）须人确认。判断不在本层（阈值开 issue，人决定）。

## 职责边界

### 做
- **健康观测**：巡检索引同步 / 脚本孤儿 / hook 漂移 / 召回命中率 / 能力边界。
- **版本治理**：CHANGELOG 完整性、版本级变更同步 README + VERSION。
- **淘汰提议**：标过期记忆/脚本 → 开 issue，**人（用户/任务所有者）决定删不删**。
- **机件保护**：守 harness 强制层（hook / settings / bootstrap）不被擅改。

### 不做
- 不自动回写三层（默认只读；fix/sync 须人触发确认）。
- 不自己删记忆/脚本（只提议）。
- 不替代确定性检查做内容判断。

## 接入流程（观测怎么启动）

```
定时 / 阈值 / 手动（control_panel / maintain.py）
  → 只读巡检：maintain.py doctor / status --json
  → 专项：scan_orphan_scripts / check_hook_alignment / check_capability_manifest
          / analyze_retrieve_log / quality_gate verify / gate_check
```

## 接出流程（观测之后）

```
出报表 JSON（只读，不改三层）
  → 问题 → 开 issue（反馈型缺口 → global issues/ → 人工门 → PR → 改 harness → close）
  → 安全本地修复（索引/统计/路径）→ maintain.py fix（人确认）
  → 同步 → maintain.py sync --source manual（唯一推荐手动同步入口）
```

## 本层细则

**机件保护**（从 work SKILL「不修改 hook」上提至此）：
- **不擅自改 harness 强制层**（hook / `settings.json` / `bootstrap.py`）。改前须向用户确认；改后必同步 `harness/hook_manifest.json` + CHANGELOG + 跑 `check_hook_alignment.py`。
- 这不是跨项目行为铁律（故不进 CLAUDE.md），是维护层职责边界：hook 是本层管的机件。

**版本治理**：
- 修改 `global-memory/` 后必追加 CHANGELOG（≥1 行：改了什么 + 为什么）。
- 版本级变更（feat/新 skill/新 hook/架构改动）→ 同步 README Release Notes + VERSION。
- 新增/删除 topic 文件 → `../MEMORY.md` 索引同步（MEM-03）。

**只读边界**：doctor/status/report/各 check_* 默认不写文件不提交不推送；写动作显式 opt-in。

> 阈值（过期天数、孤儿判定）/ 各脚本实现 = 操作细则，下沉 script 旁。人类工具手册见 `../docs/guide/MAINTENANCE.md`（不进本规格，那是操作面）。

**运营参考**（本层产出/维护，非规格）：
- `../docs/工具组件总览.md`：有哪些工具、归哪层、新工具怎么接入（全表 `../docs/scripts-registry.md`）。
- `../docs/主循环与日志地图.md`：环里有哪些 hook、各日志在哪/怎么读/啥内容（接线 `../docs/hook-chain.md`）。

## 引用的全局铁律（链接 `../agents/CLAUDE.md`）

- R9 恢复边界 / R10 Fail loud / R18 审查只报告（巡检只报告不擅改）。

## 强制点

见 `../docs/spec/RULE_ENFORCEMENT_MATRIX.md`。本层多为**只读巡检**（S2/S3），非 PreToolUse 硬拦：
- hook 漂移 → `check_hook_alignment.py`（S2）
- 脚本孤儿 → `scan_orphan_scripts.py`（S2）
- 危险命令 → `dangerous_command_blocker`（S1，唯一硬拦）
- AI 代码质量门 → `quality_gate.py`（S2 证据校验）
