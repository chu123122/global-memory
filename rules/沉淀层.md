# 沉淀层规格

> 同构骨架：定位 → 职责边界 → 接入 → 接出 → 本层细则 → 引用铁律 → 强制点。
> R 编号权威 = `../RULE_ENFORCEMENT_MATRIX.md`。

## 定位

把执行层产生的「值得跨会话记住的事」固化进记忆库。**纯契约层**：定写入规范，不判对错（值不值得写 = 执行层 AI 触发，准不准 = lint 确定性校验）。

## 职责边界

### 做
- 定**写入规范**：写什么/不写什么、frontmatter 骨架、keywords/tags 约束、模板套用、去重。
- 定**触发表**（本层是触发表唯一源）：什么信号 → 写哪个分类。
- 定**接出契约**：怎么入库（lint）、怎么被召回（供反馈层）、怎么淘汰。

### 不做
- 不判知识对错（lint 只查格式，不查内容真伪）。
- 不主动决定写不写（执行层 AI 按触发表判，本层只接）。
- 不召回（召回 = 反馈层）。

## 接入流程（信号 → 入库）

```
执行层触发（命中触发表）→ Read 对应模板（照搬 frontmatter 骨架）
  → 写入前去重（查目标文件最近 20 行，重复加 <!-- 可能重复，待清理 -->）
  → 直接用工具写文件 + 回答简述写了什么 + [MEMORY_WRITTEN]
  → harness_memory_lint.py 自查 → 通过入库
```

**触发表（唯一源；接入索引/CLAUDE 只导航过来，不复述）**：

| 信号 | 目标分类 |
|------|---------|
| 知识盲区 | `knowledge/` |
| Bug | `fixes/` |
| 面试话术 | `interview/` |
| 风格纠正 | `feedback/` |
| 跨项目规范 | `decisions/conventions.md` |
| 架构决策 | `decisions/` |
| "记住这个" | 上述对应分类（按内容归类，非新建） |

## 接出流程（入库后）

```
入库 → MEMORY.md 加一行指针（索引同步，否则维护层巡检报错）
  → 反馈层每轮按 keywords/tags 召回（本层只提供可召回结构，不参与召回判断）
  → 月度 memory_cleanup 清去重标记
  → 淘汰由维护层提议、人决定（本层不自删）
```

## 本层细则

**frontmatter 硬约束**（`memory_lint_gate.py` 拦）：
- 必有 `---` 起止，含 `description` / `trigger.keywords` / `trigger.tags`。
- `keywords` 1-5 个，**带命名空间前缀**（`tool:`/`concept:`/`error:`/`cmd:`/`platform:`），从用户原话挑高频术语，不凭空造。
- `tags` ≤5 个，**必须**来自 `../harness/scripts/triggers_vocab.yaml` 的 `domains` 列表。
- `last_updated: YYYY-MM-DD`，`status: active`。

**模板**（写前必 Read，照搬骨架）：`../templates/memory_{feedback,knowledge,fixes,decision}.md.tmpl`。

**CHANGELOG 分级**（写入即记，不攒）：
- `knowledge/`、`interview/` 的**追加** → 不需 CHANGELOG（高频低风险）。
- `decisions/`、`feedback/` 任何操作 → **必须**写 CHANGELOG（影响全局行为）。
- 任何文件的 UPDATE（覆盖）/ DELETE → **必须**写 CHANGELOG。批量合并一条。

**纠正分类**：知识点错 → `knowledge/`；风格/格式纠正 → `feedback/`。

> 阈值/脚本实现（去重行数、vocab 全表、lint 规则细节）下沉 script 旁。

## 引用的全局铁律（链接 `../agents/CLAUDE.md`）

- R9 恢复边界（写库失败只改输入）/ R10 Fail loud（写失败不掩饰）。

## 强制点

见 `../RULE_ENFORCEMENT_MATRIX.md`。本层：
- 记忆 frontmatter/keywords/tags 合规 → `memory_lint_gate.py`（S1 PreToolUse 拦）。
- 记忆文件保护（删/覆盖确认）→ `memory_file_protector`（S1 ask）。
- 索引同步 → 维护层巡检（S2，见 `维护层.md`）。
