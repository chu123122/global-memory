## 1. 整体架构(基于 PySide6,等价 v1 的功能边界)

```
QMainWindow
  └─ QSplitter(水平)
       ├─ QTabWidget(左侧 7 页签,QScrollArea 包裹各页)
       │    ├─ 总览 / 修复 / 同步 / 守护 / AI / 事件 / 历史
       │    └─ 每页内容用 QVBoxLayout + QScrollArea
       └─ QStackedWidget(右侧结论面板,QScrollArea 包裹)
            └─ 同步从 model 层读结论 → QLabel / QTextEdit
```

**关键 widget 选择**(对应 Tkinter widget):

| Tkinter v1 | PySide6 v2 |
|---|---|
| `tk.Notebook` | `QTabWidget` |
| `tk.Frame + Canvas + Scrollbar` | `QScrollArea`(内建滚动) |
| `tk.Text`(只读) | `QTextEdit` 设 readOnly,或 `QPlainTextEdit` |
| `tk.Treeview`(事件列表) | `QTreeWidget` 或 `QListWidget` |
| `tk.Button` | `QPushButton` |
| `tk.PanedWindow`(左右分隔) | `QSplitter`(可拖拽) |
| `tk.after()` 定时刷新 | `QTimer.timeout.connect()` |

## 2. 复用现有 model 层(零改动)

```python
from harness.control_panel_model import (
    summarize_status, summarize_doctor, summarize_sync_preview,
    summarize_recent_events, summarize_outcomes,  # 待 Phase 4-B reader 加
)
```

**model 层契约**:每个 `summarize_*` 返回 `dict`,view 层只负责渲染——不在 view 里写业务判断。这是 v1 的 V1.2 重构成果(REVIEW-2026-04-24-1445.md 评审中加分项),v2 直接受益。

## 5. 与 harness-governance-v1 的接口契约

| harness-governance-v1 产物 | v2 如何使用 |
|---|---|
| `task_outcomes.jsonl` schema(Phase 4-A) | view 层"账本"页按 schema_version 分支渲染 |
| Phase 4-B reader 框架 | view 层直接 import reader,不再自己解析 jsonl |
| RULE_ENFORCEMENT_MATRIX(Phase 1-B) | view 层"规则"页面渲染矩阵表格 |
| harness_status.py(Phase 2-A)| view 层"总览"页直接 invoke + 渲染 JSON |

**这意味着 v2 的实现可以渐进推进**:Phase 4-B reader 没就绪也能先做主框架 + 静态页面;接入是后期的事。
