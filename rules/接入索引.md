# 接入索引

> AI 接入本 harness 的主目录。CLAUDE.md（常驻铁律）一行指到这里。
> 人类向架构导览不在此——见根目录 README。
> 不是大目录：只承载「主目录」+「非 skill 入口」两类。

## 0. 架构模型（双轴 · 接入第一眼）

> 一套模型，两条**正交轴**，别当层级嵌套。旧 README「L1 Rules→L2 Skills→L3 Subagent→L4 Scripts」线性链已废止（category error）。

- **运转轴 HOW（用什么把每步钉死 · 钉法）**：核心三层级 `Rules → Skills → Script`（抽象高→低、确定性低→高，能用下层就不用上层）+ `harness` 旁挂（独立包裹层：强制执行 + 自动触发 + 隔离，CLI 无关，hook 只是 Claude Code 实现）。
- **设计轴 WHAT（数据怎么流 · 生命周期）**：核心闭环 `执行 → 沉淀 → 反馈 →（回）执行` + `维护` 旁挂（闭环外，只观测统计三层健康）。**本索引 §1 及 `rules/` 四份层规格说的就是这套。**

两轴正交，应然分布（格子图，■=主导 / 配=配角 / 空=不用）：

| WHAT＼钉法 | Script | Skills | Rules | harness（旁挂） |
|-----------|--------|--------|-------|----------------|
| 执行 | 产物外形(配) | 套路(配·全局+局部) | 层规格■ | 强制门 + 按需隔离■ |
| 沉淀 | schema/lint + 结构兜底■ | — | 层规格■ | 落盘前强制 lint■ |
| 反馈 | 检索+排序+截断■ | — | 层规格■ | 无脑每轮触发■ |
| 维护 | 聚合+趋势告警■ | — | 层规格■ | 定时触发 + 阈值开 issue■ |

- **Skills 只落执行层**，其余空白；空白格落了组件 = 缺陷信号。
- **判断不入格**：判断 = AI 残余（住执行层）+ 人（principal），不是钉法、不建模成组件。
- **Subagent**：理应是比 Skills 更高的独立一层，当前不需要 → 已暂移除（**DORMANT**）；非 harness 隔离子功能、非伪层。按需分派仍走 Agent tool 直调。

> 要懂「每步怎么钉」→ 运转轴 HOW（README 架构段）；要懂「数据怎么流」→ 设计轴 WHAT（下方 §1）。
> 历史名「三层金字塔（Script→Skill→Agent）」= 运转轴三机制的取用次序偏好（能用下层就不用上层），非独立架构。

## 0.1 投递通道契约（内容类型 → 走哪条通道）

> 双轴模型回答「每步怎么钉 / 数据怎么流」，**这一节回答「内容该走哪条通道到 AI」**——防止每次新需求都重拍"该上 hook 还是 skill 规范"。
> 来源：`global-memory-pull-architecture` 结构审查（2026-06-18）。

| 通道 | 触发 | 适合的内容类型 | 不适合 | 裁决权 | 现有实现 |
|---|---|---|---|---|---|
| **注入 push** | 每轮/每 prompt 自动（hook） | 常驻硬规则（铁律 R1-19）、当前 task 锚（HANDOFF/北极星/阶段卡）、高频**字面可召**的 task 内经验 | 跨语言/换说法才能召的经验；低频大文档 | hook 注入，AI 被动看 | `CLAUDE.md` 常驻 + `retrieve_inject`（**字面引擎**）+ changelog/sync/route_check |
| **检索 pull** | AI 主动调 / 固定动作点确定性触发 | 跨项目/跨会话经验、换说法/英文召回（**语义引擎**专长）、grep 物理够不着的库 | repo 内检索（grep 更准，file:line）；已注入的常驻内容（伪需求） | **只投候选指针，永不裁决；判断归 AI**（阈值小杂库剃刀边缘，不可当硬 gate） | `gm_search`（**语义引擎**）+ deliver-gate |
| **动作点门 gate** | 特定动作 PreToolUse 拦截（确定不可绕）或 work 固定动作点显式 probe | 机械纪律（写记忆需 frontmatter、改 task 文档需先读 spec、危险命令）；anchored 规则证据（实现/审查/收尾前查 R13/R17/R18 等） | 需 AI 判断的软建议（门只拦确定性违规） | 代码裁决（确定性）；`gm.rule` 只给 anchored verdict/source，不赌自然调用 | `memory_lint_gate`/`doc_gate`/`memory_file_protector`/`dangerous_command_blocker` + `gm.rule` backend probe |

**关键契约行（钉死，防未来漂移）**：

1. **同一内容不跨通道重复**：已每轮注入的（铁律/锚）不进检索评测分母（`injection_covered` 是通道契约，非临时分类）。
2. **检索通道恒为候选供给**：永不把 `intent_matches`/`suggested_answer_refs` 当答案投，永不用 confidence 当硬门槛（deliver-gate 主投递只该是 pointers）。
3. **门只拦确定性违规**：需要判断的归 AI（注入/检索辅助），门不做软建议。

4. **主动 pull 触发点**：遇到“之前做过什么 / global-memory 里有什么 / 规则在哪 / 当前配置是什么”先用 `gm.map` / `gm.locate` / `gm.inspect` / `gm.answer` 查权威入口或 anchored verdict；当前 hook/MCP/RAG 运行状态仍优先走 deterministic runtime/config brief，不靠语义阈值猜。

**两引擎分立（防误判）**：`retrieve_inject`（字面：keyword/alias/fuzzy 打分，零向量）与 `gm_search`（语义：bge-m3 向量 + intent_bank）是**两个不同引擎**，不是"一个引擎两个入口"。**禁据"同后端"错误前提去统一两套入口**——那会把每轮快字面召回拖进 warm-model 语义引擎，违"格外快"。两者唯一共性是"都产出指针供 AI 判"（设计哲学一致），不是实现重复。

## 1. 主目录：四层规格在哪、何时加载

判断只住执行层（AI+人），外三层纯契约。按需 just-in-time 加载，走显式相对路径（本文件在 `rules/`，层规格同目录）。

| 层 | 规格文件 | 何时加载 | 主拉手 |
|----|---------|---------|--------|
| 执行层 | `执行层.md` | 推进任务、code review、TDD、路由判断时 | work SKILL Step3 链入 |
| 沉淀层 | `沉淀层.md` | 要写记忆、拿不准写哪/什么格式时 | 沉淀触发（见下 §2.1） |
| 反馈层 | `反馈层.md` | 几乎不用 AI 读（hook 自动跑）；想懂召回契约时读 | — |
| 维护层 | `维护层.md` | 巡检/版本治理/改 hook 前 | maintain 入口 / 改机件前 |

## 2. 非 skill 入口：没被 slash/hook 自动接的需求

### 2.1 写记忆 → 去哪

触发信号（盲区 / bug / 风格纠正 / 跨项目规范 / 架构决策 / 面试 / "记住这个"）→ 对应分类。

**完整触发表 + 模板 + lint = `沉淀层.md`「接入流程（信号→入库）」（单一源）**，本索引不复述，只导航过去。

### 2.2 维护 → 跑哪个

| 想做 | 入口 |
|------|------|
| 只读总检查 | `maintain.py doctor` |
| 安全本地修复 | `maintain.py fix`（人确认） |
| 提交同步 | `maintain.py sync --source manual` |
| 人类主控台 | `../harness/control_panel.bat` |

全套工具手册（人类向）见 `../docs/guide/MAINTENANCE.md`。

### 2.3 想懂某层怎么运作 → 读哪份

→ 见上 §1 主目录，按层取 `<层>.md`。

### 2.4 系统拓扑导航

- task 文档 / 记忆库**位置** → `project_registry.json` 单一源（机制细节在操作细则，不在此）。
- 条文↔强制点映射（哪条铁律被哪 hook 以什么强度强制）→ `../docs/spec/RULE_ENFORCEMENT_MATRIX.md`。
- **有哪些工具 / 归哪层 / 新工具怎么接入** → `../docs/工具组件总览.md`（全量逐脚本表在 `../docs/scripts-registry.md`）。
- **主循环里有哪些 hook / 各日志在哪怎么读** → `../docs/主循环与日志地图.md`（接线顺序契约在 `../docs/hook-chain.md`）。

- 学习 → `/learn`（skill 自动）
- 每轮记忆召回 → `retrieve_inject.py`（UserPromptSubmit hook 自动）
