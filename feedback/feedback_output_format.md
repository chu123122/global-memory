# 输出格式要求

## 代码输出
- 代码块必须标注语言
- 长输出用折叠（<details>）

## 回答风格
- 直接给方案，少说废话
- 有争议时列出 trade-off
- 不确定时明说"我不确定，建议验证"

## 文档格式
- 标题层级不跳级
- 表格对齐
- 长文档有目录
