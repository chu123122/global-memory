# Requirements · token-cost-governance

> 文档类型:需求分析
> 创建:2026-04-24
> 任务目录:`projects/token-cost-governance/`
> Status: implementation

## 1. 这是什么

把高频流程里的机械上下文搬运、结构校验、目录扫描下沉到脚本,降低 AI token 消耗。核心不是再造一个大 harness,而是复用现有 `maintain.py` / `maintenance_manifest.json` / registry,补一组只读小脚本,让 AI 只处理语义判断、方案取舍和最终解释。

本任务从 `harness-governance-v1` 独立出来,避免把"运行治理"和"Token 成本治理"混成一个大任务。

## 2. 当前问题

| 问题 | 当前表现 | 代价 |
|---|---|---|
| `/work` 前置成本高 | AI 反复读 `MEMORY.md`、HANDOFF、registry、任务文档后再手工总结 | 每次启动都消耗大量上下文 |
| Skill 审计靠 AI 列清单 | `skill-auditor` 仍写着 `audit_skill.py` 尚未实现 | YAML、行数、引用文件检查不该占 AI token |
| `/check` 前置扫描靠 AI | AI 自己解析任务目录、查缺文档、找 TODO/占位符 | design-reviewer 的上下文被机械信息污染 |
| Review / Bug / Memory 流程也有重复搬运 | diff、日志、历史 fixes、frontmatter、CHANGELOG 常靠 AI 手工整理 | 高频重复劳动,且容易漏格式 |
| 部分状态脚本有只读副作用风险 | `harness_status` / `doctor` / smoke import 可能写 `STATUS_SNAPSHOT.md`、`__pycache__` 或其他缓存 | "检查"动作会污染工作区,影响可信度 |

## 3. 范围

### 本期纳入

| 序号 | 产物 | 作用 |
|---|---|---|
| 1 | Read-only purity 修复 | 确保 `maintain doctor/status`、预检脚本默认不改 tracked 文件 |
| 2 | `harness/audit_skill.py` | 把 Skill 结构审计从 AI 清单改为 deterministic check |
| 3 | `harness/work_context_pack.py` | 给 `/work` 输出当前任务短摘要、缺失文档、下一步建议、最小 Read 清单 |
| 4 | `harness/check_prepare.py` | 给 `/check` 输出待审文档、缺失项、TODO/占位符、prompt 输入清单 |
| 5 | Skill 入口改造 | `/work`、`/check`、`skill-auditor` 优先消费脚本短摘要 |
| 6 | manifest 接入 | `maintenance_manifest.json` 增加 `token_savers` 分组,供后续面板/maintain 发现 |

### 延后纳入

| 产物 | 延后原因 |
|---|---|
| `review_preflight.py` | 先等前三个脚本证明收益,避免脚本膨胀 |
| `bug_pack.py` | Bug 场景输入差异更大,需要从真实案例抽 schema |
| `memory_add.py` | 涉及写入与审计日志,安全边界比只读脚本更高 |

### 明确不做

- 不新增 HTTP/MCP/daemon。
- 不重做 control panel。
- 不让脚本自动执行修改或自动提交。
- 不新增大控制器;只做薄脚本和入口接线。
- 不把长文档全文塞进脚本默认输出。

## 4. Phase 拆分

## 6. 风险与边界

| 风险 | 代价 | 缓解 |
|---|---|---|
| 脚本输出太长,反而不省 token | AI 仍要读大量摘要 | 默认输出 ≤120 行;详细结果只走 `--json` / `--verbose` |
| 脚本误判任务 | AI 接错上下文 | 输出 `confidence` 和候选列表;低置信只提示,不自动决策 |
| 结构检查被误当语义审查 | 漏掉真正设计风险 | 明确脚本只做 preflight/audit,AI 仍负责语义判断 |
| 脚本数量继续膨胀 | 维护成本上升 | 首批只做 3 个,其余必须等使用数据证明收益 |
| 写入脚本提前介入 | 可能破坏记忆/审计一致性 | 本期坚持只读;`memory_add.py` 另起设计 |
