# SPEC 模板 — 任务启动前的验收契约

> 位置：~/.claude/skills-repo/_bootstrap/templates/SPEC.md
> 用途：任何非平凡任务开始前，先填这个模板。AI 和你都以此为唯一验收标准。
> 核心原则：如果不能定义"什么算完成"，就不该开始。

---

## 使用方式

1. 复制此模板到任务目录
2. 填写所有 `[必填]` 项
3. 把填好的 SPEC 作为 Agent 的第一条输入
4. 任务结束时，逐条验收 `完成标准`

---

```markdown
# SPEC: [任务名称]

## 元信息
- 日期：[YYYY-MM-DD]
- 发起人：[你 / 谁提的需求]
- Agent：[学习 Agent / 工作 Agent]
- 预估轮数：[几轮对话]
- 关联文件：[涉及的代码/文档路径]

## 1. 目标（一句话）

[必填] 这个任务做完后，世界会有什么不同？
> 示例：ModuleA 不再依赖 ModuleB，可以独立编译。

## 2. 背景与约束

### 2.1 为什么要做
[必填] 不做会怎样？做了解决什么痛点？

### 2.2 硬约束（不可违反）
- [ ] [必填] 列出所有不可妥协的条件
> 示例：不修改引擎源码、不破坏现有 API、编译通过

### 2.3 软约束（尽量遵守）
- [ ] [选填] 列出偏好但可商量的条件
> 示例：尽量用现有工具链、代码风格保持一致

## 3. 完成标准（验收清单）

> 每一条必须是**可客观判定**的——能由脚本验证或人一眼看出 Yes/No。
> 禁止模糊表述如"代码质量高""设计合理"。

- [ ] [必填] 标准 1：具体描述
- [ ] [必填] 标准 2：具体描述
- [ ] [选填] 标准 3：具体描述

### 自动验证项（对应 scripts/ 中的检查）
- [ ] `check_cpp_syntax.sh` 通过
- [ ] `check_lua_syntax.sh` 通过
- [ ] `format_check.sh` 通过
- [ ] `verify_output.sh` 通过

## 4. 输入（Agent 需要什么）

| 输入 | 格式 | 来源 |
|------|------|------|
| [必填] | 文件/口述/链接 | [你提供 / 仓库中已有] |

## 5. 输出（Agent 交付什么）

| 输出 | 格式 | 存放位置 |
|------|------|---------|
| [必填] | .cpp/.md/... | [具体路径] |

## 6. 不做什么（边界）

> 明确列出 Agent 不应该碰的东西，防止越界。

- [选填] 不修改 xxx 文件
- [选填] 不改变现有接口签名

## 7. 风险与降级

| 风险 | 概率 | 降级方案 |
|------|------|---------|
| [选填] | 高/中/低 | [怎么处理] |

---
## 验收记录（任务完成后填）

- 验收日期：
- 完成标准达成：_/_ 项
- 未达成项及原因：
- 后续 Action：
```

## SPEC 填写示例

以"多线程资源加载插件预研"为例：

```markdown
# SPEC: UE 多线程资源加载插件预研

## 元信息
- 日期：2026-04-13
- 发起人：个人（入职准备）
- Agent：工作 Agent
- 预估轮数：2-3
- 关联文件：knowledge/docs/async-resource-loading-preresearch.md

## 1. 目标
产出一份技术预研文档，包含 3+ 个设计方案对比和推荐方案的完整接口设计。

## 2. 背景与约束
### 2.1 为什么要做
入职心动后的第一个任务，需要带着预研方案入职，减少上手时间。

### 2.2 硬约束
- [ ] 不阻塞 GameThread
- [ ] 兼容 UE 现有资源管理体系（不绕过包加载）
- [ ] 加载出的 UObject 正确纳入 GC

### 2.3 软约束
- [ ] 尽量复用 TaskGraph/FQueuedThreadPool
- [ ] 尽量作为 Plugin 实现

## 3. 完成标准
- [ ] 文档包含 3+ 个方案的优劣对比表
- [ ] 推荐方案有完整 C++ 接口（LoadAsync/CancelLoad/GetStatus/Tick）
- [ ] 每个方案说明了与 UE GC 的交互方式
- [ ] 有测试方案和性能指标定义

## 4. 输入
| 输入 | 格式 | 来源 |
|------|------|------|
| UE 资源管理现有方案 | AI 知识 | Agent 内部知识 |

## 5. 输出
| 输出 | 格式 | 存放位置 |
|------|------|---------|
| 预研文档 | Markdown | knowledge/docs/async-resource-loading-preresearch.md |

## 6. 不做什么
- 不写实际代码（只写伪代码/接口）
- 不修改任何现有文件
```
