# 面试真题积累

## C++ 基础（米哈游出现率 >80%）
| 题目 | 来源 | 答题状态 | 备注 |
|------|------|---------|------|
| 智能指针原理和使用（shared/unique/weak） | 多次面试 | ✅ 能讲清 | Control Block、循环引用、lock() |
| 多态（静态/动态） | 腾讯一面 | ⚠️ 忘了两个 | 虚函数/模板/重载 |
| 移动语义 | 腾讯一面 | ⚠️ 答错过 | std::move 只做类型转换，被 move 对象合法但未指定 |
| 虚函数底层（vptr/vtable） | 米哈游 | 🔴 必背 | vptr 在对象头，vtable 在 .rodata，构造时初始化 |
| 构造函数能否为虚函数 | 米哈游 | 🔴 必背 | 不能——构造时 vptr 还没初始化 |
| 析构函数为什么要虚 | 米哈游 | 🔴 必背 | 基类指针 delete 派生类→不虚则只调基类析构→内存泄漏 |
| new vs malloc | 米哈游 | 🔴 必背 | new 调构造+抛异常+返回类型指针，malloc 返回 void* |
| vector 扩容机制 | 米哈游 | ✅ | 2 倍扩容→新内存→拷贝→释放旧→迭代器失效 |
| map vs unordered_map | 米哈游 | ✅ | 红黑树 O(logn) 有序 vs 哈希 O(1) 无序 |
| 内存对齐 | 米哈游 | ✅ | 空类 1 字节，虚函数加 vptr（x64=8），按最大成员对齐 |
| 四种 cast | 米哈游 | ⚠️ | static/dynamic/const/reinterpret |
| static 关键字 | 米哈游 | ⚠️ | 静态局部/静态成员/类外 static |
| 深拷贝 vs 浅拷贝 | 米哈游 | ✅ | 浅拷贝共享底层→double free |
| enum vs enum class | 面试实战 | ⚠️ 答偏过 | enum class 强类型+作用域+可指定底层类型 |
| (i++)++ vs ++(++i) | 米哈游 | 🔴 | i++ 返回右值不能再++，++i 返回左值可以 |

## 心动二面（终面）完整记录

> 面试官：心动引擎组负责人 | 整体评价：实习+AI 工具加分，C++ 多线程扣分严重

### 表现统计
- ✅ 正确 7 处：主动补充帧同步、实习描述、加速编译、三级权限、线程池、Command Buffer、AI 工具
- ⚠️ 表述不清 8 处：追帧渲染、内存序说不出、ECS 偏题、双缓冲跑题、通知主线程说不清、多线程接口不熟、事件驱动混淆、UE 线程模型
- ❌ 错误 0 处

### 关键教训
1. **C++ 多线程是致命短板** — 整场面试核心考这个，但说不出 std::thread/mutex/atomic/future/condition_variable
2. **回答系统设计题容易跑题** — 面试官问插件加载，先讲 ECS 再讲双缓冲，被两次引导才回正题
3. **"子线程通知主线程"被追问 4-5 次都没给出具体方案** — 标准答案是 atomic/future-promise/condition_variable/回调
4. **AI 工具使用是亮点** — 心动引擎组有 AI 方向，Vibe Coding 展示加分

### 面试官透露的信息
- 实习第一个任务：插件维护（包括并行加载——就是面试设计题）
- 后续可能接触：渲染功能 / AI UI 生成 / 移动端 SDK 接入
- 部门技术难点：火炬之光全局光照（屏幕空间 GI）、心动小镇 UGC 性能优化
- 转正名额不确定，取决于表现
