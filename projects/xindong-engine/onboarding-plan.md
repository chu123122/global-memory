# 心动入职过渡 + 生活优化方案

> 生成日期：2026-04-13
> 背景：从腾讯天美（9:00-24:00）转到心动引擎中台（10:00-19:00）
> 核心原则：可持续性 > 效率。上次已经透支过了，不重蹈覆辙。

## 一、日常时间分配（可持续方案）

```
心动制度时间 10:00-19:00

07:30  起床 + 洗漱
08:00  早餐 + 面试八股（30min，手机看知识笔记）
08:30  通勤
09:30  到公司，安顿 + 看当天任务
10:00  ====== 工作 ======
12:00  午饭 + 午休（15-20min）
13:00  ====== 工作 ======
19:00  ====== 下班 ======
19:30  晚饭 + 完全放松（刷手机/打游戏/散步，不看技术）
20:30  学习时间（1.5h，严格到 22:00 结束）
22:00  运动/洗澡/放松
23:00  上床
23:30  睡着

总计：工作 8h + 学习 2h + 运动 0.5h + 自由时间 2.5h + 睡眠 8h
```

### 铁律

1. **22:00 之后不看代码** — 大脑需要从"编程模式"切换出来才能入睡
2. **周末至少留半天完全不学习** — 可持续性 > 效率
3. **学习时间固定在 20:30-22:00** — 形成习惯后不需要意志力

## 三、运动方案（最小可行）

不需要健身房，不需要器材：

| 时间 | 做什么 | 时长 |
|------|--------|:---:|
| **每 2 小时** | 站起来走一走 + 转转脖子 | 2min |
| **午休后** | 楼下走一圈 | 10min |
| **晚上 22:00** | 7 分钟 HIIT（搜 "7 Minute Workout" App）或快走 20 分钟 | 7-20min |
| **周末** | 任何喜欢的运动 1 次 | 30min+ |

**关键**：从极低门槛开始。"每天 7 分钟" 比 "办健身卡然后三天打鱼" 有效 100 倍。

## 四、作息过渡（从 24:00 → 23:30）

不要一步到位。每 3 天提前 15 分钟：

| 天数 | 入睡目标 |
|:---:|:---:|
| Day 1-3 | 24:00 |
| Day 4-6 | 23:45 |
| Day 7-9 | 23:30 |
| Day 10+ | 稳定 23:00-23:30 |

配合措施：
- 21:00 后不喝咖啡/茶
- 22:00 后手机调暗光模式
- 睡前不看刺激性内容
- 如果 30 分钟睡不着，起来做 5 分钟拉伸再躺下

## 五、饮食建议（外卖为主）

| 原则 | 具体做法 |
|------|---------|
| **蛋白质优先** | 每餐有肉/蛋/豆腐，保证大脑运转 |
| **减少高碳午餐** | 午饭少吃白米饭/面条（容易犯困），多选菜+肉的组合 |
| **水** | 工位放水杯，每小时喝一次，不要等渴了才喝 |
| **咖啡** | 最多 2 杯/天，最后一杯在 14:00 前 |
| **不要省早餐** | 哪怕只是牛奶 + 面包 |

## 六、心理预期管理

### 前两周常见的不适应

1. **"什么都不懂"的焦虑** — 正常，新人前两周的主要任务是"吸收"不是"输出"
2. **代码风格不习惯** — 先适应，不要第一周就提"我觉得应该改"
3. **节奏变化** — 从腾讯的高强度到心动的正常节奏，可能反而觉得"太闲了"
4. **社交压力** — 新团队不认识人，午饭不知道找谁。主动问 mentor "午饭一起吗"

### "心动不如想象中好"怎么办

- **区分"不适应"和"真的不好"** — 前 2 周的负面感受 90% 是不适应，不是真实评价
- **给自己 1 个月的观察期** — 1 个月后如果还觉得不好，再认真评估
- **记住来心动的目的**：拿 C++ 引擎开发经验 + 转正 offer + 秋招素材。不是来找理想工作的

### 避免"两边都不满意"的陷阱

- 不要拿腾讯的薪资/福利和心动比
- 不要拿心动的技术深度和理想中的引擎组比
- **只和自己的目标比**：我来心动要得到什么？得到了吗？
